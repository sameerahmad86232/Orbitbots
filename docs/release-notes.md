Orbit Bot 3.0 adds an Apple-inspired interface with the original Milo mascot, task/approval notifications, optional background approval checks, supported JSON bot import previews, and a self-hosted computer companion.

**Download Orbit-Bots-3.0.apk below. Android 8.0+ required.** It updates prior Orbit installations using the same signing identity. Provider API keys stay configured on the phone.

The computer service provides real Xvfb/Chromium desktop screenshots and xdotool input with mandatory approval, persistent bounded server vision jobs, schedules, shared-workspace role tokens, FTS knowledge, optional SMTP sending and IMAP inbox headers. Deploy it on your own server using computer/README.md; no server or model hosting is bundled. Remote server vision jobs require a vision model separately configured on that server. APK background notification checks are periodic, not instant push.

Verified: Android build/signature, provider/UI contracts, real Docker desktop capture and browser navigation, actual approved X11 click, approval/replay gates, scheduler/knowledge tests, loopback SMTP and a local-model-protocol fixture for the server vision loop. No paid-model inference, physical Android device, external mailbox credentials or permanent hosting was verified.

Not included: payment processing, third-party OAuth connectors, vector embeddings, image/video generation, realtime AI voice or verified proprietary Grok Bot import. JSON imports support the documented profile/message fields and provide a review before saving. This independent app does not claim to surpass or match all Grok Bot features.
